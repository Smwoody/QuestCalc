# QuestCalc

**Math made clear.**

QuestCalc is a web-based mathematics application designed to help students calculate expressions, solve equations, and work through systems of equations.

**Live Demo:** https://questcalc.onrender.com

## Features

- **Calculator:** Evaluate mathematical expressions.
- **Equation Solver:** Solve equations and display solution steps.
- **Systems of Equations:** Solve systems of equations.
- **Mobile-Friendly Interface:** Use QuestCalc on desktop and mobile browsers.

## Technology Stack

- Python
- Flask
- SymPy
- HTML, CSS, and JavaScript
- GitHub and Render
